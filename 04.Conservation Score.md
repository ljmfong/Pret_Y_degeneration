# Calculating the Conservation Score for the genes containing the deleterious SNPs

Conservation scores are calculated from the **[UCSC Genome Browser]()** to detect how conserved the gene is across taxa (e.g. vertebrates). I used the script[ _get_conservation.py_](https://github.com/google-deepmind/science-skills/blob/99f3085b/skills/ucsc_conservation_and_tfbs/scripts/get_conservation.py) from **[ucsc_conservation_and_tfbs](https://github.com/google-deepmind/science-skills/tree/99f3085bcb40514cdba7833205b3dedbf473b26d/skills/ucsc_conservation_and_tfbs)** to identify if my genes are notably conserved, and how the changes of the CDS, through "deleterious SNPs" called by snpEff and the previously pipeline, impacted the genes on a conservation level.

## Preparing files

From your VCF files, prepare them to get sequences for the genes that have the impacted SNPs:

     cat formatted_high_impact_SNPs.vcf formatted_moderate_impact_SNPs.vcf > all_impactful_SNPs.vcf
     sed -i '/^CHROM/d' all_impactful_SNPs.vcf

NOTE: A proper VCF file includes "#", so add that back as needed:

    cat header_for_vcffiles.txt all_impactful_SNPs.vcf > formatted_all_impactful_SNPs.vcf

Convert back your SnpEff/SnpSift VCF to proper VCF format:

    /Linux/jdk-17.0.5/bin/java -Xmx8g -jar ~/snpEff/SnpSift.jar rmInfo formatted_all_impactful_SNPs.vcf ANN EFF LOF > standard_impactful_SNPs.vcf 

Since you only want the SNPs that were filtered out, you can use BCFTools to get only the necessary genes:

    zgrep -f lines_to_keep.txt ~/new_Ret_SNPs/all.fem.all_LGs.indels.vcf.gz > filtered_all_fem.vcf
    bgzip filtered_all_fem.vcf
    bcftools index filtered_all_fem.vcf.gz
    bcftools consensus -f ~/assemblies/Poecilia_reticulata.Guppy_female_1.0_MT.dna.toplevel.fa test_filtered_all_fem.vcf.gz > pret_genome_SNPs_consensus.fa
    bedtools getfasta -fi ~/assemblies/Poecilia_reticulata.Guppy_female_1.0_MT.dna.toplevel.fa -bed ~/assemblies/Poecilia_reticulata.Guppy_female_1.0_MT.113.bed > genes_w_seq.fa
    bedtools getfasta -fi  pret_genome_SNPs_consensus.fa -bed ~/assemblies/Poecilia_reticulata.Guppy_female_1.0_MT.113.bed > impact_genes_w_seq.fa

I manually changed the SNPs for each gene at the CDS level, put each sequence in a new directory (snp_seq), and combined them all to form one single fasta file, as well for as for the original gene sequence (no SNP changes):

    cat snp_seq/* > P_reticulata_SNP_gene_sequence.fa
    cat original_gene_seq/* > cds_genomes_and_snps/P_retiuclata_HIgene_sequences.fa

To run UCSC Conservations, you need a coordinate file, such as a BED file. I used ucscTools to convert the SNP sequence files. It is important to note that you use the BED file that matches the one that you used for snpEff

     /Linux/ucscTools/gtfToGenePred -genePredExt ~/assemblies/Poecilia_reticulata.Guppy_female_1.0_MT.108.gtf temp_genePred.txt
     awk '{print $2"\t"$4"\t"$5"\t"$1"\t0\t"$3"\t"$6"\t"$7"\t0\t"$8"\t"$9"\t"$10}' temp_genePred.txt > ~/assemblies/Poecilia_reticulata_female_108_MT.bed
     

## Getting Orthologs and getting alignment to get conservation score:

We can use **[OrthoFiinder]()** to find orthologs of your genes containing deleterious SNPS across different vertebrates. First get OrthoFinder and you can run it in a local environment through micromamba:

     mkdir ~/bin/OrthoFinder
     cd bin/OrthoFinder/
     micromamba create -n OrthoFinder orthofinder -c bioconda -c conda-forge python=3.10

The genomes I used for OrthoFinder include: Japanese medaka HdrR (Oryzias_latipes.ASM223467v1.cds.all.fa), Xiphophorus maculatus (Xiphophorus_maculatus.X_maculatus-5.0-male.cds.all.fa), Danio rerio (Danio_rerio.GRCz11.cds.all.fa), Takifugu rubripes (Takifugu_rubripes.fTakRub1.2.cds.all.fa), Homo sapiens (Homo_sapiens.GRCh38.cds.all.fa), Gallus gallus (Gallus_gallus.bGalGal1.mat.broiler.GRCg7b.cds.all.fa), Mus musculus (Mus_musculus.GRCm39.cds.all.fa), Poecilia latipinna (Poecilia_latipinna.P_latipinna-1.0.cds.all.fa), Gambusia affinis (Gambusia_affinis.ASM309773v1.cds.all.fa), Poecilia mexicana (Poecilia_mexicana.P_mexicana-1.0.cds.all.fa), Xenopus tropicalis (Xenopus_tropicalis.UCB_Xtro_10.0.cds.all.fa). These were downloaded from Ensembl:

     python3 ~/bin/OrthoFinder_source/orthofinder.py -d -f cds_genomes_and_snps/
